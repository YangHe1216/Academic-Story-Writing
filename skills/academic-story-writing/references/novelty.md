# Novelty Reasoning and Related-Work Comparison

## Compare Substantive Scientific Claims, Not Keywords

For each relevant inspected prior work, distinguish:

| Dimension | Questions |
|---|---|
| Research question | Same scientific problem, or only adjacent domain? |
| Assumptions and setting | Same inputs, supervision, distributions, constraints, or mathematical regime? |
| Mechanism | What is algorithmically/theoretically shared, and what interaction genuinely differs? |
| Formal result | Which theorems, bounds, or properties already exist? |
| Empirical result | Which comparisons, benchmarks, or capabilities have been demonstrated? |
| Scope | What can the respective evidence actually establish? |

Surface similarity is not substantive overlap. Different names or an extra module are not automatically a publishable scientific insight. The task is to find the **strongest real distinction** and understand its importance to the current central thesis.

## Workflow

1. Extract the author's actual novelty proposition: new problem, assumption, formulation, mechanism, proof, measurement, benchmark, or insight.
2. Inspect relevant supplied/accessible source texts rather than guessing their contents from titles or keywords. Track which sources were actually checked.
3. Compare at claim level, noting genuine overlap **and** meaningful differences.
4. Classify: `SUBSTANTIVE DISTINCTNESS`, `PARTIAL OVERLAP`, `SUBSTANTIVE COVERAGE`, or `INSUFFICIENT SOURCE ACCESS`.
5. Compose a positive grounded contrast: “Prior work studies X under A; our work addresses Y under B and establishes Z.” Only assert each item if inspected sources support it.
6. If a “first,” “unique,” or “unprecedented” assertion cannot be supported after appropriate inspection, refrain from that priority word; **retain the specific demonstrable contribution**.

## Anti-Reviewer-Theater Rule

Do not assume the paper lacks novelty merely because a reviewer *could* connect it to a related technique. A speculative overlap needs research, not rhetorical retreat. Likewise, do not overstate novelty because the abstract sounds different. For `PRESERVE + WRITER/EDITOR`, incorporate only grounded contrasts into prose; reserve substantive potential conflicts for a short separate note. `REVIEWER` can investigate a broader set of source-based objections when asked.
